### 常量

格式 位宽'进制数据

3'b111 == 7	# 二进制

6'o77  == 63	# 8进制

8'd255 == 255   # 10进制

8'hff == 255	# 16进制

位宽可以省略

位宽大于数据是左边补零

位宽小于数据是左边截断

直接写参数，100 = 32'd100

## 系统函数

多数都只能在仿真中使用

~~~c
`timescale 1ns/1ps	// 1ns时间单位，1ps时间精度
    
# xxx 延迟xx个时间单位    
$display //打印信息，自动换行
$write //打印信息
$strobe //打印信息，自动换行，最后执行
$monitor //监测变量
$stop //暂停仿真
$finish //结束仿真
$time //时间函数
$random //随机函数
$readmemb //读文件函数
~~~
